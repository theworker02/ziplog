# ziplog

Zip CSV/TSV log tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/ziplog/

## Install / run

```bash
git clone https://github.com/theworker02/ziplog.git
cd ziplog
node src/cli.js
node --test
```
